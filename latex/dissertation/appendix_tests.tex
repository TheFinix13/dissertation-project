This appendix lists the 21 automated verification tests referenced in
Section~4.5, grouped as in that section. Every test was run and passed
before the final experiments in Chapter~5 were accepted. The test names
use the dissertation's current terminology rather than the older working
names kept by some functions in the code.

features use no future data & Removing the later prices from the series
  does not change any earlier feature value, so no feature is calculated
  using future information. \\
\rowsep
rolling features survive the episode boundary & Momentum on the first
  day of a month reaches back into the previous month's trading days
  rather than restarting from zero. \\
\rowsep

  episode is a finite number, and every price is positive. \\
\rowsep

  configuration contains all the features of the smaller ones, so a
  comparison between two states isolates the added features. \\

  periods are ordered in time and do not share any months. \\

\bottomrule
\endlastfoot
accounting identity holds for every policy & The sum of all daily
  rewards in a month equals the month's true change in wealth, for every
  policy and state configuration tested. \\
\rowsep
reward equals wealth change when \(\lambda = 0\) & When the risk penalty
  is switched off, the risk-aware reward gives exactly the same values as
  the wealth-change reward. \\
\rowsep

  reward without the drawdown feature raises an error, so the reward can
  always be calculated from what the agent observes. \\

  the penalised reward is never larger than the unpenalised reward. \\
