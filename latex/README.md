# Building the dissertation PDF

This folder contains the LaTeX source for the dissertation. There are three ways to turn it into a PDF, listed from fastest-to-first-build to most-reproducible.

## Option 1 — Overleaf (no install, ~5 minutes)

Best for the first preview and for collaborative reviewing with a supervisor.

1. Open <https://www.overleaf.com> and sign in (free account works).
2. Click **New Project → Upload Project**.
3. Drag the entire `latex/` folder onto the upload dialog. (On macOS you can also right-click `latex/` in Finder → *Compress* and upload the resulting `.zip`.)
4. Open `main.tex` in the Overleaf editor and click **Recompile**.
5. The PDF appears in the right pane. Download it from the PDF view's download button.

Overleaf runs `pdflatex → biber → pdflatex → pdflatex` automatically, which is what this document needs.

## Option 2 — Local install on macOS (one-time setup, then offline)

Best for offline iteration once you're past the first review.

```bash
# ~5 GB, contains everything needed including biber, mathpazo, algorithm packages
brew install --cask mactex-no-gui
eval "$(/usr/libexec/path_helper)"        # refresh PATH for the current shell

# verify
which pdflatex biber                       # both should print /Library/TeX/texbin/...

# build
cd latex
./build.sh                                 # produces main.pdf in this folder
./build.sh watch                           # rebuilds on every save (needs latexmk; ships with MacTeX)
./build.sh clean                           # removes all *.aux, *.bbl, etc.
```

If 5 GB is too much, the smaller alternative is BasicTeX (~100 MB) plus a handful of explicit package installs:

```bash
brew install --cask basictex
eval "$(/usr/libexec/path_helper)"
sudo tlmgr update --self
sudo tlmgr install biber biblatex mathpazo algorithms algorithmicx \
                   enumitem multirow tikz pgf hyperref geometry setspace \
                   subcaption booktabs xpatch
```

Then `./build.sh` works.

## Option 3 — Build inside the existing Colab notebook

Best when you are already running `02_Full_Experiments.ipynb` and want the rebuild to happen on the same GPU runtime that produced the numbers.

Colab images ship with `texlive-full` pre-installed. Add this cell at the end of the notebook:

```python
!apt-get install -y -qq biber
!cd latex && bash build.sh
from google.colab import files
files.download("latex/main.pdf")
```

(Colab's texlive does not always have biber by default, hence the explicit `apt-get install`. The full LaTeX runs in about 30 seconds on a Colab runtime.)

## Troubleshooting

| Symptom | Cause | Fix |
|---|---|---|
| `! LaTeX Error: File 'mathpazo.sty' not found.` | BasicTeX without extra packages. | `sudo tlmgr install mathpazo` (or use MacTeX). |
| `! Package biblatex Error: Biber needed for backend 'biber'.` | `biber` not on PATH. | `sudo tlmgr install biber` or `brew install biber`. |
| Bibliography shows `[?]` after build. | First pass only — bibliography hasn't been resolved yet. | `./build.sh` runs the full 4-pass sequence; using raw `pdflatex` once is not enough. |
| Out-of-date references after editing `references.bib`. | Cached `.bcf` / `.bbl` files. | `./build.sh clean && ./build.sh`. |
