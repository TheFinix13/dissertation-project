\chapter{Reproducibility Commands}
\label{app:reproducibility}

This appendix lists the exact command sequences that reproduce every table and figure in this dissertation. The commands assume a Python 3.11 environment with the dependencies in \texttt{requirements.txt} installed. The repository root is \texttt{dissertation-project/} and the active branch for the headline numbers is \texttt{epistemic-uncertainty}.

\section{Environment setup}
\label{app:env_setup}

\begin{verbatim}
git clone https://github.com/TheFinix13/dissertation-project.git
cd dissertation-project
git checkout epistemic-uncertainty
python3.11 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
\end{verbatim}

\section{Phase-1 SPY headline (Table~\ref{tab:headline_spy} and Figures~\ref{fig:equity_curves}, \ref{fig:final_value})}
\label{app:phase1_spy}

\begin{verbatim}
# Buy-and-hold and all-cash benchmarks (deterministic)
python experiments/runners/run_benchmarks.py --tickers SPY --tag spy_headline

# Baseline PPO (Arm A) — 3 seeds, 10k timesteps
python experiments/runners/run_baseline.py \
    --tickers SPY --seeds default --timesteps 10000 --tag spy_headline

# Probabilistic PPO with aleatoric uncertainty (Arm B)
python experiments/runners/run_probabilistic_agent.py \
    --tickers SPY --seeds default --timesteps 10000 \
    --uncertainty-mode aleatoric --tag spy_aleatoric

# Probabilistic PPO with epistemic uncertainty (Arm C)
python experiments/runners/run_probabilistic_agent.py \
    --tickers SPY --seeds default --timesteps 10000 \
    --uncertainty-mode epistemic --mc-passes 20 --mc-dropout 0.1 \
    --tag spy_epistemic

# Trailing stop comparators (5% and 10%)
python experiments/runners/run_trailing_stop.py \
    --tickers SPY --stop-pct 0.05 --tag spy_trail_5
python experiments/runners/run_trailing_stop.py \
    --tickers SPY --stop-pct 0.10 --tag spy_trail_10

# Aggregate into the headline table
python experiments/aggregate_results.py --tag spy_headline
\end{verbatim}

\section{The runnable walkthrough notebook}
\label{app:walkthrough_notebook}

The fastest way to verify the Phase-1 SPY headline numbers without invoking the runners one at a time is to open \texttt{notebooks/01\_Project\_Walkthrough.ipynb} and execute every cell.

\begin{verbatim}
jupyter notebook notebooks/01_Project_Walkthrough.ipynb
\end{verbatim}

The notebook fetches the data, trains the probabilistic LSTM in both aleatoric and epistemic modes, trains all three RL arms, renders the comparison table and equity curves, and finishes with the day-by-day walkthrough of Section~\ref{sec:day_by_day_walkthrough}. Wall time on a single CPU core is about five minutes.

\section{Phase-2 Colab grid}
\label{app:phase2_colab}

The Phase-2 grid is GPU-accelerated and was run to completion on the Colab T4 runtime; the numbers in Chapter~\ref{ch:results} and in Table~\ref{tab:per_ticker_phase2} are from that run. To reproduce it, open \texttt{notebooks/02\_Full\_Experiments.ipynb} in Google Colab with a T4 or A100 runtime and execute every cell. The notebook:
\begin{enumerate}
  \item Clones the repository at the \texttt{epistemic-uncertainty} branch and installs the dependencies.
  \item Verifies the GPU is available.
  \item Runs a five-minute smoke test on SPY in all three uncertainty modes.
  \item Runs the Phase-2 grid (70 tickers $\times$ 10 seeds $\times$ 50\,000 PPO time-steps $\times$ 3 arms).
  \item Runs the four-fold walk-forward grid at the extended budget.
  \item Aggregates the per-cell JSON outputs into the headline tables.
  \item Zips \texttt{experiments/results/} for download.
\end{enumerate}

Wall time on a T4 is approximately four to six hours. The downloaded results bundle populates the headline aggregate (Table~\ref{tab:phase2_headline}), the full per-ticker table (Table~\ref{tab:per_ticker_phase2}), and the walk-forward tables (Tables~\ref{tab:wf_aggregate}, \ref{tab:wf_by_fold}).

\section{Two-piece ablation of Equation~\ref{eq:probabilistic_trade_size}}
\label{app:ablation}

The ablation isolates the two halves of the contribution. Arm~D keeps the uncertainty coordinate in the policy state but disables both the trade-scaling factor and the binary risk-on guard. Arm~E activates the binary guard only and zero-masks the uncertainty coordinate in the state. Arm~F activates the continuous trade-scaling factor only and zero-masks the state coordinate. The SPY pilot at Phase-2 budget reproduces Table~\ref{tab:spy_ablation}; the 70-ticker grid is GPU-feasible on Colab (about 2--3 hours per arm on a T4).

\begin{verbatim}
# SPY pilot at Phase-2 budget (~10 minutes wall on CPU)
venv/bin/python experiments/runners/run_ablation.py --ablation state_only \
    --tickers SPY --seeds extended --timesteps 50000 \
    --tag ablation_spy_phase2
venv/bin/python experiments/runners/run_ablation.py --ablation guard_only \
    --tickers SPY --seeds extended --timesteps 50000 \
    --tag ablation_spy_phase2
venv/bin/python experiments/runners/run_ablation.py --ablation scaling_only \
    --tickers SPY --seeds extended --timesteps 50000 \
    --tag ablation_spy_phase2

# Full 70-ticker grid (Colab T4, ~5h per arm)
venv/bin/python experiments/runners/run_ablation.py --ablation state_only \
    --tickers market_sample --seeds extended --timesteps 50000 \
    --tag ablation_market_phase2
# ... and likewise for guard_only and scaling_only.

# Summary table (writes to reports/generated/stats/)
venv/bin/python experiments/compute_spy_phase2_table.py
\end{verbatim}
