\begin{abstract}
Reinforcement learning (RL) promises trading agents that learn from
experience, but markets provide no ground truth against which a broken
implementation can be detected. This dissertation adopts an
understanding-first methodology: the two canonical algorithm families ---
the Monte-Carlo policy gradient (REINFORCE) and value-based Deep
Q-learning --- are derived from first principles, implemented from scratch,
validated on games with known outcomes, and only then applied to a trading
MDP whose nine-feature state is justified feature by feature against stated
admissibility criteria, paired with a divisible-asset action model and a
fee-inclusive wealth-change reward. Library PPO is added as a third
comparator. Evaluation uses eight years of S\&P~500 ETF data under a
three-way chronological split, with the action model calibrated and the
state settled on a validation year before 24 held-out months are read once,
over six seeds and against four reference strategies.

No learned agent beats buy-and-hold on return or on risk-adjusted return.
The reason is diagnostic rather than incidental: a purpose-built test shows
that REINFORCE in every seed, and PPO in almost every seed, converge on
policies determined entirely by which actions are feasible, ignoring the
state they are given, while Deep Q-learning conditions on its state in every
run but attains only 41\% of the benchmark's return for 40\% of its
drawdown --- de-risking by holding less, not by timing. A ladder of state
representations from one feature to twelve produces no separation that
exceeds the spread across seeds, which is the predicted consequence of the
objective: under a risk-neutral wealth reward on a drifting asset the best
policy is unconditional, so a richer state has nothing to earn. Adding a
drawdown penalty makes this worse, because abstention is the cheapest way to
comply.

An audit of the project's own earlier implementation found twelve defects,
three invalidating, including a benchmark labelled buy-and-hold that
deployed capital a tenth at a time and an action granularity that placed the
benchmark beyond reach in principle; both flattered the results, and
correcting them replaced an apparent risk-adjusted victory with a measurable
shortfall. The contributions are a traceable derivation-to-implementation
pipeline, an admissibility-driven account of state design in which the
criteria decide concrete cases, a diagnostic for whether a learned policy
uses its state at all, and an evaluation framework under which a negative
result is interpretable rather than merely disappointing.
\end{abstract}
